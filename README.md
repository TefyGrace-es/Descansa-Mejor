# Descansa Mejor — versión lista para GitHub Pages

## Estructura
- `index.html`
- `assets/`
  - imágenes
  - videos

## Cómo subir
1. Sube `index.html` a la raíz del repositorio.
2. Sube la carpeta `assets` completa manteniendo exactamente ese nombre.
3. En GitHub: Settings → Pages.
4. En "Build and deployment", selecciona "Deploy from a branch".
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda.

Importante: no vuelvas a pegar los videos o imágenes como Base64 dentro de `index.html`.
